Show workings

Given X=(4−3) and Y=(1−14−4)

(a) Predict the order of matrix XY:

Matrix X has dimensions 1 × 2 and Matrix Y has dimensions 2 × 2. The inner numbers match for multiplication, and the outer numbers give the final order: 1 × 2.

(b) Explain why the inverse of Y does not exist:

Find the determinant of matrix Y:

det(Y) = (1 × −4) − (−1 × 4) = −4 − (−4) = −4 + 4 = 0

The determinant of matrix Y is equal to 0, making it a singular matrix which cannot have an inverse.

Find the value of b when the distance PQ is √8 − b:

3. The line segment YZ contains the radii YP = 1 unit and QZ = 1 unit.

4. Compute distance PQ = YZ − YP − QZ = √8 − 1 − 1 = √8 − 2.

5. Compare √8 − 2 to √8 − b.

b = 2

Find the value of 2 sin CAB given tan DCA = −5⁄12:

1. Angles on a straight line sum to 180°, so ∠ACB = 180° − ∠DCA. Since tan(180° − θ) = −tan θ, we know tan ∠ACB = 5⁄12.

2. In right-angled triangle △ABC, tan ∠ACB = Opposite⁄Adjacent = AB⁄BC = 5⁄12. Set side AB = 5 and BC = 12.

3. Use Pythagoras' theorem to find hypotenuse AC:

AC = √(52 + 122) = √(25 + 144) = √169 = 13

4. Calculate sin ∠CAB = Opposite⁄Hypotenuse = BC⁄AC = 12⁄13.

5. Evaluate expression: 2 × 12⁄13 = 24⁄13.

14.
(a) Shown below
(b) 5
Show workings

(a) If 2x − y + 5 = 0 satisfies (3x − y)2 − (x − 5)2 = 0, show that 4x − y − 5 = 0 also satisfies it:

Factorise the equation as a difference of two squares (A2 − B2 = (A − B)(A + B)):

[(3x−y)−(x−5)][(3x−y)+(x−5)]=0

(2x−y+5)(4x−y−5)=0

Since the problem states that 2x − y + 5 = 0 is a valid solution, it makes the first half of the product zero. This leaves the alternative factor, 4x − y − 5 = 0, as a mathematically required root that satisfies the equation.

(b) Hence, determine the value of x:

Solve the system of equations derived from both valid factors:

  1. 2x − y = −5
  2. 4x − y = 5

Subtract equation (1) from equation (2) to eliminate y:

(4x − 2x) = 5 − (−5) ⟹ 2x = 10 ⟹ x = 5.

For group 25 < x ≤ 30: Width = 5. FD = 40⁄5 = 8. Bar height = 8 × 2.5 = 20.

For group 30 < x ≤ 50: Width = 20. FD = 12⁄20 = 0.6. Bar height = 0.6 × 2.5 = 1.5.

(b) Calculate an estimate of the number of people whose age is under 28 years:

Take all 28 people from the first group, plus a proportional fraction of the middle class up to age 28:

People=28+(28−2530−25×40)=28+(35×40)=28+24=52

(a) State the length of AX:

The diagonals of a parallelogram bisect each other: AX = Total line AC⁄2 = 16⁄2 = 8 cm.

(b) Find the ratio of AX : XY:

Since XC = AX = 8 cm and YC = 6 cm, calculate segment length XY = XC − YC = 8 − 6 = 2 cm. The ratio is 8 : 2.

4 : 1

(c) Find the area of △CFY:

The linear scale factor (k) between similar triangles △ABX and △CFY is determined by corresponding side components along the shared diagonal: k = YC⁄AX = 6⁄8 = 3⁄4. The area scale factor is k2 = (3⁄4)2 = 9⁄16.

Area = 32 × 9⁄16 = 2 × 9 = 18
