Unit 13

Functions

1. Given that f(x)=3x2+x, find

(a) f(2),

(b) f(-1),

(c) f(a+1).

2. If h(x)=5-2x2, find k such that h(k)=-3.

3. A function f(x) is defined by f(x)=2x+1.

(a) Evaluate f(0).

(b) Find an expression for f-1(x) in terms of x.

4. Given g(x)=x2-x. Find

(a) g(4),

(b) g-1(6).

5. A function k(x) is defined by k(x)=x+1x+2, x≠-2.

Find the function k-1(x).

6. Given that f:x↦17-4x, find

(a) the value of f(3),

(b) an expression for f-1.

7. Given that f(x)=4x+3, evaluate

(a) f(-2),

(b) f-1(31).

8. Given that f(x)=3x-5, evaluate

(a) f(-4),

(b) f-1(7).

9. Given that f:x↦2x-73, find

(a) f(2),

(b) an expression for f-1.

10. Given that f(x)=5-2x, find

(a) f(-2),

(b) f-1(x).

11. It is given that f(x)=2x-7 and g(x)=x(x-6).

(a) Find the value of f(-5).

(b) (i) Obtain an expression for f-1(x).

(ii) Find the value of f-1(15).

(c) Find the values of x for which

(i) g(x)=0,

(ii) f(x)=g(x).

12. Given that f(x)=2x+35, find

(a) f(6),

(b) f-1(7).

13. Given that f(x)=2x-15, find

(a) f(8),

(b) f-1(7).

14. Given that f:x↦3x-52, find

(a) f(313),

(b) an expression for f-1.

15. Given that f(x)=x+32, find f-1(x).

16. Given that f(x)=x-23, find f-1(x).

17. Given that f:x↦7-3x4, find

(a) f(-3),

(b) an expression for f-1.

18. Given that f(x)=3x+2x,

(a) find f(-4),

(b) find x when f(x)=4,

(c) write down the value of f-1(4).

19. It is given that f(x)=5-2x3. Find

(a) f(12),

(b) f-1(-12).

20. Given that f:x↦2x+1, find an expression for f-1.

21. Given that f(x)=14(3x+1), find

(a) f(5),

(b) f-1(7).

22. Given that f:x↦2x-35, find

(a) f(4),

(b) an expression for f-1.

23. Given that f:x↦x+62x, find

(a) f(4),

(b) an expression for f-1(x).
